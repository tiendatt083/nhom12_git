Yêu cầu chấm điểm

Để hoàn thành bài tập, hãy cố tình tạo xung đột theo kịch bản này:

BƯỚC 1: SỬA CÙNG MỘT DÒNG Mở file này, tìm biến GROUP_NAME ở phần Script bên dưới. Leader đổi thành "Nhóm Vô Địch", Member đổi thành "Nhóm Chiến Thần".
BƯỚC 2: LEADER PUSH TRƯỚC Leader commit và git push origin main lên GitHub thành công.
BƯỚC 3: MEMBER BỊ REJECT & GIẢI QUYẾT Member commit local rồi chạy git pull origin main. Git sẽ báo CONFLICT. Mở VS Code chọn Accept Both/Incoming -> Commit và Push.
